# JUST CHEERS · Grape Atlas

WSET Level 3 中英對照讀書網站。

## 檔案
- `index.html` — 網站首頁（Grape Atlas）
- `design-system.html` — 設計系統說明頁
- `assets/tokens.css` — 顏色、字型、間距（改這裡，全站一起變）
- `assets/site.css` — 網站元件樣式

## 上傳到 GitHub Pages
把這個資料夾**裡面的全部檔案**（含 `assets` 資料夾）拖進 repository 的 Upload files，Commit 後到 Settings → Pages 選 main / root。
